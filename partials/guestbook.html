讨论与留言（建议）

使用 Giscus 将留言保存为 GitHub Discussions，UI 美观且在仓库中管理。若要启用，请按下方说明配置（或访问 giscus.app 生成配置）。

如何自定义外观（示例）
- 更改主题：修改 `data-theme`（例如 `light` / `dark` / `preferred_color_scheme` 或自定义 CSS URL）。
- 使用内置样式钩子：在 CSS 中使用 `.giscus`, `.giscus-frame`，或添加类如 `giscus-compact` / `centered` 来控制布局。
- 示例：将容器设置为紧凑居中（取消注释上面的 `div#giscus-container` 并保留 `class="giscus centered giscus-compact"`）。
