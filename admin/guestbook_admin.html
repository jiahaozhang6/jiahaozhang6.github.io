留言板管理

本页面帮助你在本地编辑和导出 data/guestbook.json。提交后可下载更新后的 JSON，或复制粘贴到仓库文件中。

提示：若你想使用在线留言并在 GitHub 中管理，推荐使用 Giscus（将留言保存在 GitHub Discussions）。在启用 Giscus 后，无需手动维护 data/guestbook.json。

检查并获取 Discussions 分类 ID（用于 Giscus 配置）

若要把评论保存到某个 Discussion category，你需要该 category 的 name 与 id。可选方式：

  1. 在 giscus.app 使用向导并复制页面生成的 data-* 值（最简单）；
  2. 或在本地运行仓库内的脚本查询（需 GitHub Personal Access Token）：
# 在终端运行（需设置 GITHUB_TOKEN）
python tools/check_github_discussions.py --repo jiahaozhang6/jiahaozhang6.github.io

# 或直接传入 token（不推荐在共享环境使用）：
python tools/check_github_discussions.py --repo jiahaozhang6/jiahaozhang6.github.io --token YOUR_TOKEN

脚本会列出 repository 下的 discussion categories 及对应 ID；如果返回为空，请到仓库设置启用 Discussions（Settings → Features → Discussions）。
